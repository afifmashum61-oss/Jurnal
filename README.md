# Jurnal Pegangan Guru - MA Darussalam Sengon

Aplikasi Web **Jurnal Pegangan Guru** modern berbasis React + Tailwind CSS untuk pengelolaan aktivitas harian guru, presensi siswa, jadwal mengajar mingguan, dan rekapitulasi cetak laporan resmi berstandar sekolah.

![Tampilan Aplikasi](public/foto-guru.png)

## 🌟 Fitur Utama

- **Dashboard Interactive**: Ringkasan beban jam mengajar, persentase presensi siswa, dan jadwal mengajar hari ini.
- **Jurnal Harian Mengajar**: Formulir & Log harian (Materi, Tujuan Pembelajaran / TP, Presensi, Status Ketercapaian, & Media Pembelajaran).
- **Jadwal Mengajar Mingguan**: Matriks jadwal Senin-Sabtu dengan penanda otomatis sesi berlangsung hari ini.
- **Presensi & Master Siswa**: Check-in status kehadiran (Hadir/Sakit/Izin/Alpa) dan **Impor Siswa Massal** (CSV / Copas dari Excel).
- **Catatan Kejadian Siswa**: Log prestasi & pembinaan kedisiplinan siswa.
- **Cetak Laporan Resmi PDF**: Format laporan kedinasan ber-KOP Sekolah lengkap dengan kolom Tanda Tangan Kepala Sekolah & Guru Mata Pelajaran.

## 💻 Cara Menjalankan Aplikasi

1. Clone repositori:
   ```bash
   git clone https://github.com/afifmashum61-oss/Jurnal.git
   cd Jurnal
   ```

2. Install dependensi:
   ```bash
   npm install
   ```

3. Jalankan server lokal:
   ```bash
   npm run dev
   ```

4. Buka di browser:
   `http://localhost:5173`
